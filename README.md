# MGM Resorts Ransomware Attack – Cybersecurity Case Study
## Project Overview
This individual cybersecurity case study examines the September 2023 ransomware attack against MGM Resorts. The project analyzes how social engineering contributed to the breach, the operational and financial impact of the attack, security vulnerabilities, and controls that could help reduce the risk of similar incidents.
This project was completed as part of my IBM cybersecurity training.
## Attack Overview
The attackers used social engineering and vishing techniques to obtain login information and gain access to MGM's systems. The incident resulted in ransomware deployment and disruption to several business systems and services.
## Areas Analyzed
- Ransomware
- Social engineering and vishing
- Authentication and access control
- Multi-factor authentication (MFA)
- Role-based permissions
- Security awareness training
- Security monitoring
- Network segmentation
- Data protection and encryption
- Incident impact and recovery
## Key Security Recommendations
- Strengthen employee security-awareness training
- Implement multi-factor authentication
- Apply role-based access controls
- Maintain secure backups
- Use SIEM monitoring to identify suspicious activity
- Encrypt sensitive data
- Segment networks to limit unauthorized lateral access
